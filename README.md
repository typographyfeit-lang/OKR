# OKR Daily

Мобильное PWA для ежедневного ритуала на основе OKR. Данные хранятся только в localStorage браузера.

## Публикация на GitHub Pages

1. Создай публичный репозиторий и загрузи все файлы из этой папки в его корень (Add file → Upload files).
2. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
3. Через минуту приложение откроется по адресу `https://<логин>.github.io/<репозиторий>/`.
4. iPhone: Safari → Поделиться → «На экран „Домой“». Android: меню Chrome → «Установить приложение».

## Заметки

- Данные привязаны к домену. Если раньше приложение жило на том же домене, старые данные (`okr-daily-v1`) подхватятся сами. При переезде на другой адрес сделай экспорт JSON на вкладке OKR и импортируй его на новом.
- Обновление: замени файлы в репозитории. Service worker сначала берёт свежую версию из сети, офлайн отдаёт кэш.
