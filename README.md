# OKR Daily 3 — Strategy OS

Полностью автономное PWA для личных OKR, анализа результатов и улучшения решений. Все интерфейсы — на русском.

## Установка на текущий GitHub Pages

1. Открой репозиторий `typographyfeit-lang/OKR` → **Add file → Upload files**.
2. Перетащи **все файлы из этой папки** (`index.html`, `app.js`, `styles.css`, `manifest.json`, `sw.js`, `icon-*.png`, README.md). Для существующих файлов GitHub создаст новую версию при подтверждении коммита (при загрузке через UI придерживайся инструкций GitHub по замене содержимого).
3. Дождись GitHub Pages и обнови сайт. Если старая версия закэширована, закрой PWA и открой его заново или обнови вкладку через браузер.

**Важно:** Не удаляй ключи `localStorage` на телефоне. При первой загрузке v3 автоматически импортирует данные из ключей `okr-daily-v2` или `okr-daily-v1` и **не удаляет исходные записи**. После переноса сразу экспортируй JSON в **Ещё → Настройки**.

## Новое в версии 3

- Несколько Objectives, даты, архив, корректные числовые KR (рост и снижение), журнал замеров, прогноз, фактическая и плановая траектории.
- План на сегодня и завтра (до 2 задач), привязка к KR, критерий готовности и фактическая оценка действия.
- Бэклог, рейтинг 80/20 на основании предполагаемого влияния, уверенности и времени.
- Вечерний ритуал из трёх вопросов, дополнительный SWOT, закрытие дня со снимками KR, история и возможность открытия дня на исправление.
- Недельный обзор с тремя стратегическими решениями; локальные сигналы риска и отсутствие измеримого прогресса.
- Журнал гипотез и экспериментов; OODA-журнал решений с проверкой результата.
- Таймер фокус-сессий, подсчёт времени для задач.
- Светлая и тёмная темы, резервный экспорт/импорт JSON, напоминания во время открытого приложения, PWA для установки на экран телефона.
- Подготовка текстового контекста для разбора с внешним ИИ (копирование, без передачи в сторонние сервисы из приложения).

## Честные ограничения

- **Автоматической облачной синхронизации нет.** Для неё необходимы серверный бэкенд, аутентификация, хранение с контролем доступа и политика конфликтов. Сейчас — ручной перенос через JSON.
- **ИИ внутри приложения не подключен.** Умные сигналы строятся из локальных правил; кнопка «Разбор с ИИ» копирует контекст в буфер обмена для ручной вставки в ChatGPT. Не храни API ключ на публичном GitHub Pages.
- **Фоновые push-уведомления не реализованы.** Напоминания появляются при открытом приложении; для настоящих push требуется сервер подписок, события и разрешения пользователя.
- Прогноз линейный, строится только на замерах в разные дни; он приблизительный, а не гарантия.
- Для 80/20 предполагаемое влияние — субъективная оценка, а доля «реальной отдачи» основана на оценках, введённых вручную, и не доказывает причинность.
- Поскольку данные живут в браузере, при очистке локального хранилища они могут пропасть. Рекомендуется еженедельный экспорт.

## Локальная проверка

```sh
python -m http.server 8080
```

Открой `http://localhost:8080`. Чтобы использовать PWA офлайн, нужна HTTPS-страница (GitHub Pages подходит) или localhost.

## Формат данных

Основной ключ: `okr-daily-v3`. Ранние ключи: `okr-daily-v2` и `okr-daily-v1` читаются только при отсутствии данных v3 и не перезаписываются. При импорте предыдущие текущие данные сохраняются в отдельном локальном аварийном ключе `okr-daily-v3-rollback`.
